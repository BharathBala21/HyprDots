# HyerDOTS

HyerDOTS is a complete Arch Linux dotfiles collection for Hyprland, built to feel polished, consistent, and easy to maintain.

It combines:

- automated Hyprland behavior with Lua scripting
- wallpaper-driven theming via Matugen
- a dynamic Tide Island / Quickshell widget workspace
- ready-made app configs for `kitty`, `fish`, `dunst`, `btop`, `cava`, and more

- integrated search and docs controls in the top bar

## Why this repo

HyerDOTS is designed around a source-of-truth workflow:

- repository files are the canonical config
- installs create symlinks into `~/.config`
- theme generation stays synchronized across apps
- desktop automation is centralized in `hypr/hyprlua`
