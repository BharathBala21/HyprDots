HyprDots is a complete Arch Linux dotfiles collection for Hyprland, built to feel polished, consistent, and easy to maintain.

It combines:

- automated Hyprland behavior with Lua scripting
- wallpaper-driven theming via Matugen
- a dynamic Tide Island / Quickshell widget workspace
- ready-made app configs for `kitty`, `fish`, `dunst`, `btop`, `cava`, and more

## Before you install

HyprDots targets Arch Linux and changes desktop configuration on the machine where it is installed. Before running the installer:

- review the [installation requirements](/installation)
- back up any existing configuration you want to keep
- make sure `paru` or `yay` is available for AUR packages
- expect prompts before packages, symlinks, and the default shell are changed

## Why this repo

HyprDots is designed around a source-of-truth workflow:

- repository files are the canonical config
- installs create symlinks into `~/.config`
- theme generation stays synchronized across apps
- desktop automation is centralized in `hypr/hyprlua`
