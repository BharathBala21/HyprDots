HyerDOTS is built from modular configuration layers so you can tune one area without changing the whole setup.

## Hyprland configuration

The `hypr/` folder is the desktop core.

- `hyprland.lua` — base Hyprland options and input maps
- `hyprpaper.conf` — wallpaper manager settings
- `hypridle.conf` — idle and lockscreen behavior
- `monitors.lua` — monitor layout and scaling
- `hyprlua/` — Lua automation, keybindings, and environment values

### Important `hypr/hyprlua` files

- `exec.lua` — starts `waypaper`, `dunst`, `quickshell`, `hypridle`, and clipboard watchers
- `input.lua` — gesture and touchpad controls
- `binds.lua` — workspace shortcuts, screenshot hotkeys, and widget toggles
- `windowrule.lua` — floating window rules and special placement
- `env.lua` — default apps and environment variables

## Local overrides

Use `hypr/hyprlua/custom` for machine-specific tweaks:

- keep custom local settings out of the repo
- let the repo remain the source of truth
- use overrides for personal paths, hardware quirks, or local preferences

## Theme generation with Matugen

`matugen/` builds a shared color palette from your wallpaper.

The repository uses templates for:

- `kitty`
- `yazi`
- `btop`
- `hyprland`
- `cava`
- `steam`
- `obsidian`
- `starship`
- `firefox`
- `vscode`
- `quickshell`

If you update your wallpaper, rerun Matugen and restart the relevant apps.

### Editing theme settings

Open `matugen/config.toml` to change:

- wallpaper source
- palette generation rules
- template output targets

## Tide Island and widgets

`tide-island/` contains the desktop widget shell and helper tools.

- `qml/` — UI components and screen layouts
- `bin/` — wallpaper, recording, app list, and setup scripts
- `lockscreen/` — lockscreen UI and launcher
- `shell.qml` — main shell entrypoint
- `DynamicIslandWindow.qml` — island widget container

The installer links this directory to `/usr/share/tide-island` so the runtime loads from the repo.

## App configuration directories

- `kitty/` — terminal theme and settings
- `fish/` — shell prompt and environment
- `dunst/` — notification styling
- `btop/` — system monitor theme
- `cava/` — audio visualizer settings
- `fastfetch/` — system information display

## Updating configuration

1. edit the source file in the repository
2. rerun `./install.sh` or manually reapply the config
3. restart Hyprland or the affected service

> The repository is the canonical config. Only copy files into `~/.config` when you need a local override.
