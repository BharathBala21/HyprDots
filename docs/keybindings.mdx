---
title: Keybindings
description: Essential HyprDots keyboard shortcuts for apps, workspaces, widgets, and capture tools.
---

The source of truth for shortcuts is `hypr/hyprlua/binds.lua`. `Super` is the main modifier.

## Applications and windows

| Shortcut | Action |
| --- | --- |
| `Super` + `Return` | Open Kitty |
| `Super` + `E` | Open Dolphin |
| `Super` + `C` | Open Visual Studio Code |
| `Super` + `W` | Open Zen Browser |
| `Super` + `Q` | Close the active window |
| `Super` + `F` | Toggle fullscreen |
| `Super` + `D` | Toggle maximized mode |
| `Super` + `L` | Lock the screen |

## Workspaces

| Shortcut | Action |
| --- | --- |
| `Super` + `1`–`9` | Switch to workspace |
| `Super` + `Alt` + `1`–`9` | Move the active window to workspace |
| `Super` + `Ctrl` + `Left/Right` | Move to the previous/next workspace |
| `Super` + `Tab` | Toggle workspace overview |

## Tide Island

| Shortcut | Action |
| --- | --- |
| Tap `Super` | Toggle app launcher |
| `Super` + `A` | Toggle Control Center |
| `Super` + `U` | Toggle utilities |
| `Super` + `V` | Toggle clipboard history |
| `Super` + `.` | Toggle emoji picker |
| `Super` + `Alt` + `W` | Toggle wallpaper picker |
| `Super` + `/` | Toggle cheatsheet |

## Capture and tools

| Shortcut | Action |
| --- | --- |
| `Super` + `Shift` + `S` | Capture a region |
| `Print` | Capture the current output |
| `Super` + `Shift` + `W` | Capture a window |
| `Super` + `R` | Start or stop screen recording |
| `Super` + `Shift` + `O` | Run OCR on a selection |
| `Super` + `Shift` + `B` | Read a QR code or barcode |
| `Super` + `Shift` + `M` | Open the screen mirror tool |

After editing `binds.lua`, reload Hyprland for the changes to take effect.
