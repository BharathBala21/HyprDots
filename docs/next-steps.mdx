Now that the documentation is in place, you can make HyprDots your own and keep the repo maintainable.

## Recommended next actions

- complete [Installation](/installation) if you have not already
- follow [Configuration](/configuration) to review the main folder responsibilities
- personalize behavior in [Customization](/customization)
- review [Troubleshooting](/troubleshooting) if anything needs fixing

## Personalization ideas

- replace the wallpaper and regenerate themes with Matugen
- adjust `hypr/hyprlua/binds.lua` to match your workflow
- add safe local overrides in `hypr/hyprlua/custom`
- tune `kitty`, `fish`, and `dunst` appearance in the repo
- extend the widget shell with new scripts or QML pages

## Keeping the repo maintainable

- treat the repository as the single source of truth
- avoid committing local secrets or machine-specific paths
- use the installer to refresh symlinks when config changes
- keep docs updated as you customize the setup

> This documentation is intended to be the central reference for your HyprDots workflow.
