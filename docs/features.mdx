HyerDOTS is designed to deliver a complete desktop experience with polished themes, automation, and useful utilities.

## Desktop experience

- Hyprland-based Wayland desktop
- workspace automation and window rules
- wallpaper-aware theming with Matugen
- fast launcher and widgets via Tide Island / Quickshell
- consistent app styling across terminal, notification, and widgets

## Built-in automation

- `hypr/hyprlua/exec.lua` — boots the desktop services automatically
- `hypr/hyprlua/input.lua` — gesture support and touchscreen-friendly controls
- `hypr/hyprlua/binds.lua` — workspace navigation, screenshot/recording hotkeys, and widget toggles
- `hypr/hyprlua/windowrule.lua` — floating window rules, screenshot overlays, and special workspace placement
- `hypr/hyprlua/env.lua` — default apps, environment variables, and Qt/GTK settings

## Appearance and theming

HyerDOTS uses wallpaper-driven theme generation so your desktop feels cohesive.

The repo includes theme templates for:

- `kitty` terminal
- `yazi` terminal file browser
- `btop` system monitor
- `hyprland` desktop theme
- `cava` audio visualizer
- `steam` UI theme
- `obsidian` theme snippets
- `starship` prompt
- `firefox` styling
- `vscode` editor theme
- `quickshell` widget theme

## Productivity tools

HyerDOTS provides a suite of daily-use utilities:

- `btop` for terminal system monitoring
- `cava` for audio visualization
- `fastfetch` for system information display
- `kitty` for a modern terminal setup
- `fish` for shell productivity and completions
- `yazi` for terminal file navigation

## Widget and shell integration

- `tide-island` powers the desktop launcher, dynamic island, and lockscreen
- `quickshell` provides the home screen and app launcher
- helper scripts support wallpapers, recording, and app selection

## Why it matters

HyerDOTS is more than a collection of dotfiles: it is a curated desktop setup with theme consistency, an automated install path, and a maintainable repository structure.
