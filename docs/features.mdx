HyprDots is designed to deliver a complete desktop experience with polished themes, automation, and useful utilities.

## Desktop experience

- Hyprland-based Wayland desktop
- workspace automation and window rules
- wallpaper-aware theming with Matugen
- fast launcher and widgets via Tide Island / Quickshell
- consistent app styling across terminal, notification, and widgets

## Built-in automation

Lua modules start desktop services, manage workspaces and window rules, configure input, and expose shortcuts for screenshots, recording, OCR, barcode scanning, clipboard history, emoji selection, and Tide Island panels.

## Appearance and theming

HyprDots uses wallpaper-driven theme generation so your desktop feels cohesive.

Matugen templates synchronize colors across Hyprland, Kitty, Yazi, btop, Cava, Dunst, browsers, editors, media apps, prompts, and Quickshell widgets.

## Productivity tools

The setup includes a themed terminal and shell, terminal file navigation, system monitoring, audio visualization, clipboard history, screenshots, screen recording, OCR, QR/barcode scanning, and visual search.

## Widget and shell integration

- `tide-island` powers the desktop launcher, dynamic island, and lockscreen
- `quickshell` provides the home screen and app launcher
- helper scripts support wallpapers, recording, and app selection

## Why it matters

HyprDots is more than a collection of dotfiles: it is a curated desktop setup with theme consistency, an automated install path, and a maintainable repository structure.
